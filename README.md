# make.fun — One Star, Five Stars for the Food

Bounty: https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7
Prize: $2 shared by the top 8 entries.

## Entry

`main.py` — Python, standard library only. It writes one sentence, at
most 200 characters, a one-star review of Earth by an alien tourist that
still compliments the food, to `/output/entry.txt`. The biryani earns two
stars' worth of flavour, but the planet's gravity drags the tourist
toward its core at nine-point-eight metres per second squared the entire
meal — so: one star.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
python3 main.py                          # writes /output/entry.txt
```
